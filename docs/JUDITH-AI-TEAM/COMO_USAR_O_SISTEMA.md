## 🆘 TROUBLESHOOTING

### Problema: "Agente X parece estar travado"

**Solução:**
1. Aguarde mais 2 minutos (às vezes o LLM é lento)
2. Se ainda estiver travado, pressione Ctrl+C para cancelar
3. Reabra o arquivo de log: `TESTE_CREATE_REEL_FULL.md`
4. Verifique qual agente parou

### Problema: "Conteúdo não está alinhado com a marca"

**Solução:**
1. Primeiro: Use QUICK_REVIEW para diagnóstico
2. Depois: Dispare novamente o workflow com mais contexto
3. Ex: "Tema: Chocolate Ruby — Foque em educação sobre origem, não em venda"

### Problema: "Estou com pressa, preciso de resultado em 2h"

**Solução:**
1. Use QUICK_REVIEW em vez de CREATE_REEL_FULL
2. Ou use REPURPOSE_CONTENT (mais rápido, 2-3h)
3. Aviso: Qualidade pode sofrer se cortar tempo de validação

### Problema: "Quero customizar o processo"

**Solução:**
1. Leia: `JUDITH-AI-TEAM/agents/AGENT_COLLABORATION_PROTOCOL.md`
2. Leia: `JUDITH-AI-TEAM/workflows/CREATE_REEL_FULL.md`
3. Modifique o workflow conforme necessário
4. Ou: Combine diferentes agentes manualmente
