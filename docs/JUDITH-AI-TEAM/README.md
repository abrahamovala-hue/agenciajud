# Judith AI Creative Team

> Time completo de agentes de IA para a marca **Bem me Qué** por **Judith Kolker**.

---

## 🎯 Visão Geral

Este projeto é um time de agentes de IA organizados como uma **agência criativa interna 24h** para Judith Kolker e a marca Bem me Qué — chocolataria artesanal premium.

O time é responsável por:

- 📱 Social media (Instagram, Reels, Stories, Carrosséis)
- 🎯 Marketing digital e estratégia de marca
- ✍️ Criação de roteiros, hooks, legendas e campanhas
- 📊 Análise de performance e métricas
- 🛒 Marketing de produtos digitais (ebooks)
- 🔄 Reciclagem e reaproveitamento de conteúdo
- 📝 Revisão editorial e alinhamento de marca

## 🤖 O Time (12 Agentes)

| Agente | Função |
|--------|--------|
| 🎯 Brand Strategist | Posicionamento, diferenciação, estratégia de marca |
| 📈 Marketing Director | Direção de campanhas, funis, conversão |
| 📱 Social Media Manager | Gestão do Instagram, calendário, postagens |
| 🪝 Hook Finder | Ganchos virais, aberturas magnéticas |
| 🎬 Script Writer | Roteiros para Reels e vídeos |
| ✍️ Caption Writer | Legendas, CTAs, hashtags |
| 🎨 Visual Creative | Direção de arte, composições visuais |
| 🎥 Video Editor | Briefings de edição, ritmo, cortes |
| 🛒 Product Marketing | Marketing de ebooks e produtos digitais |
| 🔍 Trend Research | Tendências, formatos virais, oportunidades |
| 📊 Metrics Analyst | Análise de dados, performance, insights |
| ✅ Brand Reviewer | Revisão final, alinhamento de marca |

---

## 📋 Como Usar

1. **Consultar a memória de marca** (`brand/`) antes de qualquer criação
2. **Escolher o workflow** adequado (`workflows/`) para a tarefa
3. **Acionar os agentes** na sequência definida pelo workflow
4. **Salvar o conteúdo** na pasta correspondente em `content/`
5. **Mover para `approved/`** após revisão do Brand Reviewer
6. **Mover para `published/`** após publicação real
