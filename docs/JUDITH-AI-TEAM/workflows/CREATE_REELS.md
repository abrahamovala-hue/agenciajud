# Workflow: Criar Reels

## Objetivo
Transformar uma ideia, produto ou momento em um Reel polido, com roteiro, legenda e CTA.

## Agentes Envolvidos
1. **Hook Finder** — Gera 5 hooks virais
2. **Script Writer** — Escreve roteiro
3. **Caption Writer** — Cria legenda
4. **Visual Creative** — Sugere visual, animações
5. **Video Editor** — Dicas de edição
6. **Brand Reviewer** — Valida tone e alinhamento

## Inputs
- Tema/ideia (string ou link)
- Tipo de Reel (tutorial, bastidor, produto, educativo, etc.)
- Objetivo (venda, engajamento, lead, etc.)
- Produtos/temas relacionados (opcional)

## Outputs
- **5 Hooks** com contexto
- **Roteiro completo** (em passos)
- **Legenda** (com CTA)
- **Visual Brief** (cores, transições, elementos)
- **Checklist de edição**
- **CTA sugerido**

## Passos

### 1. Análise do Tema
- Hook Finder analisa o tema
- Pensa em ângulos virais
- Considera audience de Bem Me Qué

### 2. Geração de Hooks
- 5 opções de hooks
- Cada uma com variação de tom
- Pronto para A/B testing

### 3. Desenvolvimento do Roteiro
- Script Writer transforma hook em roteiro
- Estrutura: Setup → Clímax → CTA
- Duração: 15-60 segundos

### 4. Legenda e CTA
- Caption Writer cria legenda
- Inclui hashtags relevantes
- CTA claro (link, DM, comentar, etc.)

### 5. Direção Visual
- Visual Creative sugere:
  - Paleta de cores
  - Transições
  - Grafismos/elementos
  - Música/som sugerido

### 6. Revisão
- Brand Reviewer valida
- Se não passar, volta pro script writer

## Exemplo

**Input:** "Produto novo: Cobertura de chocolate ruby"

**Output:**
- Hook 1: "Esse chocolate é ROSA e é real... 🤯"
- Hook 2: "A cor do chocolate que te deixa CONFUSA"
- Hook 3: "Você QUER saber como fiz esse rosa 👀"
- Roteiro completo com passos
- Legenda pronta para copiar-colar
- Brief visual
- Checklist de edição

## Tempo Estimado
5-10 minutos (agentes rodando em paralelo)

## Arquivo de Saída
`content/ideas/reel_YYYYMMDD_[titulo].md`
